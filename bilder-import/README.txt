Galerie-Bilder importieren
==========================

So funktioniert es:

1. Neue Fotos in den passenden Ordner ziehen:
   - babybauch
   - neugeborene
   - familie
   - hochzeit

2. Im Hauptordner doppelklicken:
   galerie-bilder-importieren.bat

3. Das Script erstellt automatisch:
   - optimierte WebP-Bilder im Hauptordner
   - responsive Versionen im Ordner responsive
   - Galerie-Eintraege in Deutsch, Englisch und Bosnisch

4. Die Originaldateien werden danach nach _verarbeitet verschoben.
   Dadurch wird beim naechsten Start nichts doppelt eingefuegt.

Optional: eigener Alt-Text
-------------------------

Wenn ein Bild z.B. DSC1234.jpg heisst, kannst du daneben eine Datei
DSC1234.alt.txt legen.

Inhalt:

de=Babybauchfoto mit Partner beim Babybauch Shooting in Graz
en=Maternity photo with partner during a maternity session in Graz
bs=Trudnicka fotografija sa partnerom u Grazu

Wenn keine .alt.txt Datei vorhanden ist, nimmt das Script passende Standardtexte.
